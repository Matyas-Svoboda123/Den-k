# Projekt ALM – Deník


## Jazyk a verze

- **Jazyk:** Java
- **Verze:** Java 17
- **Rozhraní:** konzole


## Ovládání

Po spuštění je deník prázdný. Operace se zadávají jako text a potvrzují Enterem. Aplikace vždy zobrazuje celý aktuální den s očíslovanými záznamy, počet dnů, počet záznamů v aktuálním dni a seznam dostupných operací (kromě potvrzování mazání).

| Operace | Co dělá |
|---|---|
| `predchozi` | přejde na předchozí den |
| `dalsi` | přejde na následující den |
| `zacatek` | přejde na první den |
| `konec` | přejde na poslední den |
| `novy` | přidá nový záznam |
| `smaz` | smaže vybraný záznam aktuálního dne |
| `uloz` | uloží deník do souboru |
| `nacti` | načte deník ze souboru |
| `zavri` | ukončí program |
